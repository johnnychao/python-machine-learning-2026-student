## AI Solution Practicum Sources

The current integrated practicum uses Kaggle links only to acknowledge the original challenge or project context. Its Colab runtime does not use KaggleHub, Kaggle credentials, competition downloads, `kaggle-environments`, or Gradio.

- CNN runtime data: `tf.keras.datasets.cifar10.load_data()` downloads CIFAR-10 from the University of Toronto source and the Notebook filters class 3 (cat) and class 5 (dog). Keep the CIFAR-10 attribution and review the [official dataset page](https://www.cs.toronto.edu/~kriz/cifar.html) before reuse beyond this classroom exercise.
- RNN runtime data: the `startificial/twitter-nlp` CSV on Hugging Face, pinned to commit `bb1c6925112f570ea0ca94c723ff8818cc642eed`. The dataset repository metadata identifies the package as MIT-licensed; the individual social-media messages may still contain personal, offensive, or otherwise rights-sensitive content and should remain within the teaching exercise.
- Style-transfer inputs: course-created ImageGen illustrations stored under `data/ai_solution_practicum/assets/`. The generation tool, date, prompts, repository paths, and SHA-256 records are preserved in `docs/assets/illustrations/image-prompts.md`. No Monet artwork or Monet dataset image is redistributed by this package.
- Style-transfer model: Google Magenta Arbitrary Image Stylization from TensorFlow Hub is used as a fast classroom proxy; the exercise does not claim to train or execute CycleGAN.
- Reinforcement-learning runtime data: none. The Connect X board, moves, and evaluation games are generated by pure Python code inside Colab.
- Cinematic background score: `Snow Globe` by Bobjt, downloaded from [OpenGameArt.org](https://opengameart.org/content/snow-globe), is distributed under [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/). The author states that attribution is not required; this project retains voluntary credit and an integrity record in `docs/assets/audio/SNOW_GLOBE_LICENSE.txt`. The MP3 is bundled locally and plays only after an explicit user click.

Exact runtime URLs, fixed revisions, checksums, classroom scope, and authentication policy are recorded in `data/ai_solution_practicum/datasets.json`.
