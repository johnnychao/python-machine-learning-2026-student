### 1. 本章學習路線

前面的監督式學習使用已知標籤訓練模型；本章改處理沒有標籤的資料。你將使用聚類方法找出客戶消費紀錄中的群組結構，並比較不同分群結果。

本章由監督式學習轉向非監督式學習（Unsupervised Learning）。聚類分析（Clustering）會依特徵相似度將資料分組，可用於客戶分群、文章主題探索與推薦系統前處理。

接下來，我們將學習如何從無序的資料點中，提煉出具備商業價值的結構化資訊。

### 2. 學習目標 (Learning Objectives)

完成本章後，你將具備以下四大核心能力：

### 3. 核心觀念白話理解

K-means 可拆成以下反覆執行的步驟：

**A. K-means：隨機選組長，鄰近找組員**

K-means 就像是開學第一天的分組遊戲，其核心是最小化「群內誤差平方和 (SSE)」：SSE\=j\=1∑ki\=1∑nw(i,j)∥x(i)−μ(j)∥2

**選組長**：隨機指定 k 個人當「質心 (Centroid)」。

**指派群集**：計算每筆資料與各群集中心的歐幾里得距離，指派給最近的中心。

**換組長**：每一組成員到齊後，取所有成員特徵的平均值，選出「新組長」。

**重複更新**：反覆執行指派與更新，直到群集結果收斂。

**技術洞察**：K-means 假設群集是「球形 (Spherical)」的。如果資料長得像半月型，它會分得很痛苦。

**B. 階層式分群 (Hierarchical Clustering)：尋找家族血緣**

這是一個從小族群不斷合併到大族群的「凝聚式 (Agglomerative)」過程：

**合併邏輯**：一開始每個人都是獨立族群，接著讓「最相似」的兩個族群合併。

**技術細節（Linkage）**：

**完整連結 (Complete Linkage)**：比較兩個族群中「最不相似（距離最遠）」的成員，以此作為合併依據。這種方法較為穩健。

**單一連結 (Single Linkage)**：則是比較「最相似（距離最近）」的成員。

**樹狀圖 (Dendrogram)**：這像是一張「族譜」，呈現了親疏遠近。你可以決定在哪裡「砍一刀」，來決定最終的分群數量。

**C. DBSCAN：鄰里的人口密度**

這不再是看中心點，而是看「人擠不擠」。

**核心點 (Core Point)**：**「風雲人物」**。在半徑 epsilon 內，住著超過 MinPts 個朋友。

**邊界點 (Border Point)**：**「跟班朋友」**。朋友不夠多，但至少住在風雲人物的半徑範圍內。

**噪音點 (Noise Point)**：**「邊緣邊緣人」**。附近沒鄰居，也不是風雲人物的朋友。

**優勢**：它能識別任何奇形怪狀的分佈（如半月型），且能自動識別並剔除雜訊。

### 4. 重要術語中英對照表

| 英文術語 | 中文對照 | 定義簡述 |
| --- | --- | --- |
| Unsupervised Learning | 非監督式學習 | 在沒有標籤的情況下尋找資料模式。 |
| Prototype-based clustering | 原型分群 | 每個群集由一個中心代表（如 K-means）。 |
| Centroid | 質心 / 中心點 | 群集中所有樣本特徵的平均位置。 |
| Inertia (Within-cluster SSE) | 慣性 / 群內誤差平方和 | 衡量點與其質心的緊密程度，Scikit-learn 中稱為 inertia_。 |
| Elbow Method | 手肘法 | 觀察 SSE 下降速度的轉折點以決定最佳 k 值。 |
| Silhouette Coefficient | 輪廓係數 | 衡量樣本與同群的相似度 vs 他群的差異度 (-1 ~ 1)。 |
| Agglomerative Clustering | 凝聚階層分群 | 「由下而上」逐步合併樣本的分群法。 |
| Dendrogram | 樹狀圖 | 呈現階層分群合併過程的視覺化工具。 |
| Core Point | 核心點 | 在指定半徑 (epsilon) 內擁有足夠鄰居點的樣本。 |
| Curse of Dimensionality | 維度災難 | 在高維空間下，歐幾里得距離會失效，點與點距離都差不多。 |

### 5. 程式碼流程導讀：Scikit-learn 實作重點

在寫程式時，請想像你正在引導機器進行一場科學實驗：

**為什麼一定要做「特徵縮放 (Feature Scaling)」？**這是初學者最容易忘記的。想像資料中有「年薪 (0 - 1,000,000)」與「年齡 (20 - 60)」。如果你不做縮放，年薪上 $100 的微小差異，在數學距離上會遠大於年齡 1 歲的差異，導致年齡特徵完全被「淹沒」。因此，使用歐幾里得距離前，請先經過 `StandardScaler`。

**KMeans 的參數小技巧**：

`n_clusters`: 決定要分幾組。

`init='k-means++'`: 這是「聰明種子」法，讓初始質心盡量拉開距離，避免模型分得太爛。

`n_init`: **這就像是在擲骰子**。因為 K-means 結果受初始位置影響很大，我們會執行 10 次，挑選 SSE 最低的那次作為最終答案，避免運氣不好抽到爛初始點。

**DBSCAN 的兩難設定**：

`eps` (半徑)：這是對「鄰居」的定義。設得太小會增加噪音點；設得太大則可能合併原本不同的群集。

### 6. Google Colab 實戰操作步驟

**環境與資料準備**：使用 `make_blobs` 產生實驗用的球型資料，或用 `make_moons` 產生半月型資料來考驗演算法。

**模型訓練與預測**：呼叫 `fit_predict(X)`。記住，非監督式學習不需要傳入 y（標籤）。

**視覺化檢查**：繪製散佈圖時，針對 K-means，務必用紅星標註 `cluster_centers_`，這能讓分群邏輯一目了然。

**模型體檢（重點！）**：

**手肘圖**：注意！手肘點不是下降最快的地方，而是**「改善速率明顯趨於平緩」**的那個轉折處。

**輪廓圖**：使用 `silhouette_samples` 繪製。好的分群在圖中應該呈現**「厚度均勻」且「長度相近」**。如果出現極薄的「小刀片」形狀，代表該群集可能包含許多離群值或分類不當。

輪廓係數公式：s(i)\=max{b(i),a(i)}b(i)−a(i)，目標是接近 1。

### 7. 常見錯誤與排除 (Troubleshooting)

**K-means 效果看起來很糟糕？**

檢查資料是否為非球形（長條狀、弧形）。若是，請改用 DBSCAN。

再次確認你是否有做 `StandardScaler`。

**會出現空群集 (Empty Clusters) 嗎？**

別擔心，Scikit-learn 的實作很聰明。如果某個群集變空了，它會自動尋找離目前質心最遠的點，並強制將其指定為新質心。

**維度災難 (Curse of Dimensionality)**：

如果你有 100 個特徵，距離計算會變得毫無意義。**實作建議**：先用 PCA（主成分分析）將資料壓縮到 2 或 3 維，再進行分群。這不僅能解決數學問題，還能讓你畫出散佈圖來視覺化驗證。

### 8. 動手練習與自我檢查表

**動手練習題**

**觀念題**：請比較「硬分群 (Hard Clustering)」與「軟分群 (Soft/Fuzzy Clustering)」的差異。

**提示**：K-means 屬於「硬分群」（每個人只能屬於一組，非 0 即 1）；而 **Fuzzy C-means** 屬於「軟分群」，它給出的是樣本屬於各組的機率（例如 85% 屬於 A 組，15% 屬於 B 組）。

**實作題**：請在 Colab 中調整 DBSCAN 的 `eps` 參數。觀察當半徑從小變大時，半月型資料的分群會如何從較多噪音點逐步形成兩個主要群集。
