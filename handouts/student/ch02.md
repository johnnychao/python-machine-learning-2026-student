## 2. 核心觀念：感知器 (Perceptron) 的直覺與限制

人工智慧的基石源於 1940-1950 年代對生物大腦處理電訊號與化學訊號的研究。

### 感知器的運作直覺：嚴格的守門員

我們可以將感知器想像成一個**「評分機制」**。當資料（特徵）進入模型時，各項特徵會被賦予權重。守門員計算「特徵 × 權重」的加總，得到一個「淨輸入」分數。

**數學替代與簡化：**為了計算方便，我們引入 **偏誤項 (Bias Unit)**。我們定義 w0\=−θ（θ 為門檻值）且對應的特徵 x0\=1。這使得原本的判斷式 w1x1+...+wmxm≥θ 可以簡化為：z\=w0x0+w1x1+...+wmxm\=wTx若 z≥0，預測為類別 1；反之為 −1。

### 重要術語中英對照表

| 中文術語 | 英文術語 (符號) | 定義 / 作用 |
| --- | --- | --- |
| 感知器 | Perceptron | 1957 年由 Rosenblatt 提出，能自動學習權重的二元分類演算法。 |
| 權重 | Weights (w) | 代表各個特徵對決策影響力的係數。 |
| 偏誤項 | Bias Unit (w0) | 基礎底分，數學上由 w0=−θ 換算而來，讓決策邊界能平移。 |
| 特徵 | Features (x) | 樣本屬性，如鳶尾花的花瓣長度。 |
| 淨輸入 | Net Input (z) | 特徵與權重的線性組合，即 wTx。 |
| 激勵函數 | Activation Function (phi) | 決定神經元是否發射訊號；感知器使用「步階函數」。 |
| 學習率 | Learning Rate (η) | 更新權重時的步伐大小，通常介於 0.0 與 1.0 之間。 |
| 線性可分 | Linearly Separable | 資料點能被一條完美的直線（或超平面）完全切開。 |

### 感知器的收斂限制

感知器僅保證在資料為「線性可分」時收斂。若紅圈與藍叉資料互相混雜，演算法會為了一兩筆錯誤而不斷大幅修改權重，導致無限迴圈。因此，實作時必須設定**「最大訓練回合數 (Epochs)」**以確保程式能適時中止。

為了克服這種「僵化」且僅能處理二元分類的侷限，科學家隨後演化出更具彈性的 Adaline 演算法。

## 3. 演算法進階：Adaline 與梯度下降最佳化

Adaline (ADAptive LInear NEuron) 引入了**「連續性激勵函數」**，這是現代機器學習最佳化理論的起點。

### 感知器與 Adaline 的關鍵對比

**更新依據：**

**Perceptron (增量更新)：** 根據「預測類別是否正確 (+1/-1)」來更新。每看一筆資料就更新一次。

**Adaline (批次更新)：** 根據「連續預測分數與真實標籤的落差」來更新。它計算整個資料集的誤差後再統一口最佳化。

**成本函數：** Adaline 旨在最小化 **誤差平方和 (SSE)**：J(w)\=21∑i(y(i)−phi(z(i)))2。

**數學特性：** Adaline 使用線性激勵函數 phi(z)\=z，使成本函數變為「連續且可微」的凸函數 (Convex)，讓我們能運用微積分求導。

### 梯度下降 (Gradient Descent) 的數學直覺

梯度下降可以比喻為**「下山找谷底」**。

**原理：** 我們朝著梯度的「反方向」移動權重，以尋找 SSE 的全球最小值。

**學習率 (**η**) 的兩難：** 這是步伐大小。步伐太大會發生「越過谷底」(Overshoot)，導致誤差不降反升，甚至數值溢位 (NaN)；步伐太小則效率過低，耗費運算資源。

### 特徵標準化 (Standardization) 的影響力

當特徵單位差異很大（如公分與毫米）時，SSE 成本函數的等高線會呈狹長橢圓形，使梯度下降路徑大幅震盪，降低收斂效率。

透過標準化（平均值 0、標準差 1），等高線會較接近圓形，權重更新路徑也會更直接。

### 延伸思考：多類別分類

雖然感知器與 Adaline 天生是二元分類器，但透過 **One-vs.-All (OvA)** 技術，我們可以為每個類別訓練一個分類器。預測時，選擇「淨輸入」絕對值最高的類別作為結果，即可解決多類別問題。

## 6. 常見錯誤與動手練習

### 常見錯誤與排除手冊

| 現象 | 可能原因 | 對策 |
| --- | --- | --- |
| Loss 變成 NaN 或無限大 | 學習率 (η) 過大，導致權重在山谷間彈跳發散。 | 將學習率調小一個數量級（如從 0.01 降至 0.001）。 |
| 學習曲線不降反升 | 未執行特徵標準化，或權重更新方向（正負號）錯誤。 | 檢查 X_std 標準化步驟；確認梯度更新是相加而非相減。 |
| 模型永遠無法收斂 (Error > 0) | 資料為非線性可分，或迭代次數 (Epochs) 不足。 | 檢查散佈圖；對於非線性資料，感知器無法達到 0 誤差。 |
