### 3. 重要術語中英對照與說明

**導言與學習重點**機器學習是跨學科領域，術語統一至關重要。同一概念在統計學與電腦科學中常有不同稱呼（如 Sample vs. Instance），消除這種混淆感是建立「資料思維」的基礎。

**重要術語對照表**

| 中文術語 | 英文術語 / 同義詞 | 關鍵定義 |
| --- | --- | --- |
| 樣本 | Sample / Instance / Observation / Record | 資料集中的一橫列。註：在統計文獻中，Sample 有時指代整個資料樣本集。 |
| 特徵 | Feature / x / Predictor / Attribute / Covariate | 資料集中的直行，用於預測的自變數。 |
| 目標 / 標籤 | Target / y / Label / Dependent variable / Ground truth | 想要預測的答案，即響應變數。 |
| 分類 | Classification | 預測離散且無序的類別標籤（如：垃圾郵件辨識）。 |
| 回歸 | Regression | 預測連續性的數值結果（如：房價預測）。 |
| 分群 | Clustering | 探索式分析，將相似特徵的樣本聚集為子群體（Subgroups）。 |
| 降維 | Dimensionality Reduction | 壓縮資料維度，去除雜訊（Noise）並保留關鍵資訊。 |
| 泛化能力 | Generalization | 模型對未見過的新資料做出準確預測的能力。 |

**實際意義：損失函數 (Loss) vs. 成本函數 (Cost)**在模型最佳化中，**損失函數**衡量的是「單一資料點」的誤差；而**成本函數**則是整個資料集上所有損失的平均或總和。區分兩者對梯度下降等最佳化演算法至關重要，因為我們最終調教的是整體的代價。

**歷史筆記：為何叫「回歸」？**「回歸」一詞由 Francis Galton 於 1886 年在其遺傳研究中提出。他觀察到高個子父母的後代，身高往往不會更極端，而是會「回歸」（Regression）到人口的平均身高。這在今日演變為預測連續數值的技術代名詞。

### 4. 資料的數學表示法：特徵矩陣與向量

**導言與學習重點**將現實事物抽象化為矩陣，是為了實現電腦的高效批次運算（Vectorized operations）。這不僅是數學需求，更是現代機器學習效能的基石。

**資料解剖導讀：以鳶尾花 (Iris Dataset) 為例**

**結構**：150 筆樣本，4 個特徵。

**特徵矩陣** X：寫作 X∈R150×4，代表一個 150×4 的二維陣列。

**目標向量** y：寫作 y∈{Setosa,Versicolor,Virginica}150。

**數學符號規範**

**大寫粗體** X：代表矩陣（Matrix）。

**小寫粗體** x(i)：代表第 i 個樣本（列向量）。

**下標** j：代表特徵維度。

**範例**：x1(150) 代表第 150 筆樣本的第一個特徵（例如：花萼長度）。

### 5. 機器學習開發管線 (Roadmap)

**導言與學習重點**模型訓練並非唯一重點。根據 **David Wolpert 的「天下沒有白吃的午餐」(No Free Lunch) 定理**，沒有任何一個演算法能完美解決所有問題。因此，嚴謹的前處理與評估階段對模型成敗具有決定性影響。

**開發流程解析**

**步驟一：前處理 (Preprocessing)**：包含特徵縮放（Scaling）與降維。若特徵單位不一（如公分 vs. 公斤），會嚴重拖慢收斂速度。

**步驟二：學習 (Learning)**：在此階段進行模型選擇。基於「沒有最優演算法」的哲學，我們通常會比較多種模型並調校**超參數 (Hyperparameters)**。

**步驟三：評估 (Evaluation)**：必須切分**訓練集 (Training Set)** 與**測試集 (Test Set)**。不得在開發過程中使用測試集調整模型，否則會導致對泛化能力的過度樂觀。

**步驟四：預測 (Prediction)**：將最終模型部署於全新資料。

### 7. 常見錯誤排除與學習自我檢查

**導言與學習重點**機器學習專案的成敗常在細節。建立預警機制不僅是除錯，更是對模型品質的控管。

**常見錯誤分析**

**錯誤一：Garbage in, garbage out**。忽視前處理（如未作特徵縮放）會導致模型失效。

**錯誤二：過度擬合訓練集**。在學習階段死背資料，導致泛化能力低落。

**錯誤三：維度誤判**。隨時檢查 `X.shape`（樣本 × 特徵）與 `y.shape` 是否對齊。

**動手練習與自我檢查表 (Defensive Checklist)**

- [ ] **場景辨識**：預測明天的氣溫是「回歸」還是「分類」？

- [ ] **術語對齊**：你能解釋 Covariate 與 Feature 其實是同一件事嗎？

- [ ] **數學定義**：在符號 x2(10) 中，上標與下標分別代表什麼意義？

- [ ] **評估原則**：為什麼我們**不應使用**測試集（Test Set）來調整模型的超參數？

- [ ] **延伸思考**：David Wolpert 的「沒有白吃的午餐」對你選擇演算法有何啟發？
